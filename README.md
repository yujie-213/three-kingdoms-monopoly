# 三国大富翁

原生 HTML/CSS/JavaScript + Vite，无后端。**v1.7.0 免费 / 五折锦囊铺版**：新增胜利、失败和中途出局战报，展示经营成绩、真实关键轮次与破产资金缺口，可继续观战或重开。三处锦囊铺停靠后可免费随机领取，或购买固定展示的一张五折牌，二选一；空城计最多持有一张，免费领取采用个人五种牌袋。40格、魏蜀吴、1玩家+2AI，默认经典无限轮直到其他势力破产；经济沿用3200起步、分段补给、城组收入、付费骰点调度、拆建筑筹款与商业繁荣。保留桌游美术、掷骰演出和自动恢复。

权威需求：[PROJECT_SPEC.md](PROJECT_SPEC.md)。原始资料包保留在 `three_kingdoms_monopoly_docs/`；根目录规范已按用户最新要求更新；原始资料包保留旧版基线，后续以根目录规范为唯一维护入口，不并行修改两份。

## 安装、开发、验证

要求 Node.js >=22.12（本次使用 24.21.0）、npm；浏览器自动测试默认使用 Windows 已安装的 Microsoft Edge。

```powershell
npm ci
npm run dev
```

打开终端显示的本地地址，通常为 `http://127.0.0.1:5173`。点击顶部“新局设置”，选择玩家阵营、模式和经济预设后开始。每次新局自动生成随机种子；需要复现对局时，可在“高级设置”里输入种子；掷骰，购买/升级可确认或放弃，结束回合后 AI 自动行动。桌面采用三栏布局：左侧玩家与记录、中央棋盘、右侧操作与土地详情；棋盘随窗口尺寸缩放，主要信息在一屏内展示，无主地为米色，魏红 / 蜀黄 / 吴蓝表示占地，并配阵营旗帜；设施采用独立图形。三方角色概况同时可见且没有滚动条，对局记录默认展开并有独立滚动区；骰点显示在操作标题旁的浅底标签中，购买/升级费用分行排列，确认与放弃同排，操作区无需滚动；角色明细与较长土地详情按需展开。鼠标悬停或键盘聚焦锦囊可查看效果。普通/快速/跳过等待只改变演出时间，暂停会锁定行动。开发页面会加载 Vite 本地模块/HMR，这是开发工具行为。

```powershell
npm test                # Vitest 游戏核心 + 发布依赖检测
npm run build           # 单 HTML 构建 + 强制资源检查
npm run verify:release  # 单独复查已有产物
npm run test:browser    # 先构建，再运行：开发页 + 离线 file:// Edge
npm run test:share      # 先构建：空文件夹中的单 HTML，Edge + Chrome 断网对局/存档
npm run check           # 顺序执行上述测试、构建、浏览器测试
npm run simulate        # 90 个种子样本，写入 docs/reports/simulation-economy-v5.json
npm run release         # 全部验收后生成带版本号的 HTML + SHA256
npm run prepare:pages   # 仅准备 pages-artifact/index.html，不上传
```

浏览器测试自行启动/停止 5173 端口的开发服务；运行前停止已开的 `npm run dev`。Windows 默认使用本机 Edge；若有 Chrome，可设置 `$env:BROWSER_CHANNEL='chrome'` 重跑。`test:share` 使用已安装的 Edge 与 Chrome，也可设置 `$env:CHROME_TEST_EXECUTABLE` 指向便携 Chrome 测试版。v1.5本轮使用 Edge 154.0.4258.62 验证；Chrome分享验收入口保留，此前版本使用过Google官方Chrome for Testing 155.0.8059.39。Linux CI 配置使用 Playwright Chromium（需 `npx playwright install --with-deps chromium`）；该远程流程尚未执行。普通开发无需 Playwright。

## 发布与离线打开

构建命令为 `npm run build`。确切产物：

```text
D:\GptWork\three-kingdoms-monopoly\dist\三国大富翁.html
```

带版本号的分享文件：`D:\GptWork\three-kingdoms-monopoly\releases\三国大富翁-v1.7.0.html`，约15.7 MB。旁边的 `.sha256` 用于校验，分享时只需发送HTML。发布脚本不覆盖同版本的不同内容。

把上述 HTML 作为文件发送给朋友。接收者下载到电脑后，双击或拖入 Edge / Chrome 即可开始；如果聊天软件只显示代码或预览，请先下载文件，再用浏览器打开。玩家无需 Node、服务器、素材文件夹或网络。现金不足先卖地筹款（需再次确认），资产仍不足才破产。限轮在完整 40 轮后结算；经典在只剩一名存活者时结束。

`file://` 自动测试禁用网络，检查资源请求和页面错误；覆盖四个 PC 尺寸、完整 40 轮和经典对局、存档、免租、出售确认、速度切换及重开。另将 HTML 单独复制到临时空目录，在 Edge 与 Chrome 中离线完成40轮，再导出并恢复终局存档，确认接收者无需源码或素材目录。具体结果见 [docs/VALIDATION.md](docs/VALIDATION.md)。本版面向电脑浏览器。

## 玩家操作与数值

点击“我的城池”查看地产、财富历程和锦囊铺。掷骰前或行军结束后可主动升级，每回合与落点升级共用一次机会；刚买的城池下回合才可升级。收齐城组租金+30%及每圈80/120金经营收益；三城组拥有两座租金+15%。个人完成第一圈后可建三级，零散城也能建设。城组不是历史行政区划。

空城计免本次租金，最多持有一张；千里走单骑掷骰前+2格；生财有道+100金；修城令使本回合一次升级费用减半；商路兴盛对己方一城增加25%租金，到使用轮次+3轮开始失效，不叠加。每回合最多主动用一张，免租响应另计，背包最多三张。仅实际停靠颍川驿、隆中或江东集市后，可免费未知随机领取，或购买本次唯一展示的五折牌，二选一；结束回合失效，经过/下回合原地停留不算；隆中不再固定赠送空城计。颍川驿原补给、江东集市原税费保留。五折售价：空城计75、千里走单骑30、生财有道60、修城令40、商路兴盛50金；特价商品随停靠固定，读档不刷新。

锦囊铺免费领取、江东渡口和妙计偶得使用个人牌袋：五种打乱后依次发放，发完再洗牌，读档保留顺序；已持有空城计时改抽下一张。固定赠送和购买不消耗牌袋；背包满时明确替换或放弃，放弃的牌也算已抽取。商店领取时即消耗机会，满包放弃也不能再买；购买须有空位。AI同样遵守二选一与持有规则。

胜败战报在终局自动显示；玩家提前出局则显示出局战报，不提前宣布冠军。阅读时暂停AI，点击继续观战恢复；可收起战报查看棋盘，右侧“查看战报”可再次打开。资产曲线、三方明细和日志按需展开，关键事件使用实际轮次，破产资金快照在资产清空前保存。

标准经济：初始3200；前两圈每圈500金分四段领取，之后每圈300，经过起点另领完整城组收入。地价150/250/400，租金10%/35%/100%，建设60%/100%。每圈可付60金调度首骰±1，与加步互斥；欠款可拆建筑按实际层成本60%回收，保留土地与城组。24座持有城及6座三级城触发商业繁荣，此后每12个完整轮次租金倍率+0.25，固定收入与建设成本不变。规则细节见[经济系统](docs/ECONOMY_V5.md)。标准经典30场规则模拟全部结束，平均98.83轮，90角色前两圈无被迫处置资产；这是规则AI模拟，不代表人类试玩时长或平衡证明。

## 保存与恢复

随时导出JSON备份，包含玩家、土地、RNG、个人牌袋、设施停靠机会、关键战报、每回合限制和经营统计。导入先严格校验，再确认替换。支持v7及旧40格v3/v4/v5/v6，保存落点选择、调度次数与繁荣进度；旧档保留原经济及已有锦囊，锦囊铺采用免费 / 五折二选一，特价商品与牌袋均保存；旧版缺失的战报从恢复后开始记录。v3财富统计从恢复开始累计。旧24格存档仍明确拒绝。

浏览器允许localStorage时，每次成功行动自动保存，并保留上一份有效快照；刷新恢复当前流程，移动中的落点只结算一次。损坏时尝试上一份备份，两份均损坏则暂停并保留原档，等待导入或新局。存储被禁用或写满时显示“请导出备份”，游戏仍可使用；file://的存储行为由浏览器决定，不能作为唯一备份。仅PC单机，无联机、账号或后端。

JS、CSS 与所有运行图片全部内联；使用系统字体和本地 Web Audio 合成提示音（默认关闭，点击开启）。美术原始 PNG 保留，网页使用逐像素验证一致的无损 WebP。素材来源与提示词见 [assets/LICENSE.md](assets/LICENSE.md) 和 [v2 美术记录](docs/art/tabletop-assets-v2.md)。不使用 CDN、API、追踪或在线素材。新增素材必须源码导入，不用 public/。未内联资源会导致构建失败；HTML/CSS 与 JS AST 检查结合离线浏览器请求记录验证发布链路。

`dist` 属于可再生成产物。构建不会自动清空该目录；若里面有非本工程生成的文件则拒绝构建，需人工移走后重试。

## 目录与边界

```text
src/core/    纯状态转换、动作校验、轮次、资产、系统/玩家债务、RNG、存档
src/config/  已确认约束与待确认实验默认值分开保存
src/data/    40 格地图、四区域、三阵营角色注册表、12 种事件与3种锦囊
src/ai/      不含种子/RNG 的公开视图与保守/激进决策，共用 dispatch
src/ui/      地图、Q版肖像、决策、日志、结算、演出与提示音
src/main.js  入口连接层
assets/      生成的桌游美术PNG与无损WebP、原始SVG及素材说明
scripts/     单文件构建、验证、模拟、版本发布和Pages产物准备
tests/       unit/规则/存档/发布检查，browser/真实离线操作
docs/        规则、决策、任务、交接
```

core 接收状态和合法指令，返回新状态及事件日志，不访问 DOM 或动画计时。UI 发送意图，AI 使用同一入口且看不到 RNG。角色/阶段/revision 校验拒绝重复结算；控制器的局代号和调度版本取消旧演出与导入异步任务。移动动画不消耗随机数，逻辑落点只结算一次。

## Git 与维护

初始无 Git 仓库，M0 新建 `main`，没有提交、remote 或推送。保留全部原始资料文件。`.gitignore` 排除依赖、构建、缓存、测试报告、密钥和本地存档；提交源码、文档与 `package-lock.json`，不要提交 `.env` 或凭据。示例环境文件只能含假值。`.gitignore` 不能防止已跟踪文件泄密，提交前仍需检查 `git diff --cached`。

源码与自动生成发布文件分开：`dist/`、`releases/`、`pages-artifact/`、缓存、测试截图与私人存档忽略提交。接力见 [docs/HANDOFF.md](docs/HANDOFF.md)。
