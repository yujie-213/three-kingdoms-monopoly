## M1 原型决定（2026-10-09）

用户已要求继续后续阶段，本轮按 M1 最小可玩闭环推进。费用歧义已向用户询问，尚未收到答复，采用可配置、未最终确认的原型默认：升级支出 0.75P / 1.00P，租金 0.15P / 0.40P / 0.90P，四舍五入为整数；理由是将 §3 主列作为升级成本、备注“收费”作为租金解读。总资产暂按现金+实际投入，同分并列。用户可后续调整，不能把此决定当作最终产品确认。

## M2–M5 首版完成决定（2026-10-09）

用户要求持续完成整个项目，普通待定项继续沿用可配置默认，不再停下来确认。实现经典/限轮模式、严格版本化 JSON 存档、12 种事件、3 种锦囊、保守/激进 AI、原创 SVG Q 版人物/城池与地图装饰、帮助/音效开关、离线验收和反馈模板。暂不自动部署 GitHub Pages（规范可选；未配置 remote/账号）。

默认：事件按类别权重后均匀有放回抽取；锦囊满背包可放弃或替换指定一张；一次回合最多一场急行军额外骰，额外落点仍结算，重复急行军仅提示；跳过机会计入轮数；三个设施分别赠现金/纳固定税/赠锦囊，主题格为小额补给或空城计。所有金额与触发参数集中配置。经典模式不设轮数终止，限轮默认40。存档导入失败不改当前局，合法存档显式确认替换；快照包含待移动/待决策/债务/额外骰/跳过等流程状态；不读取 localStorage。

费用/总资产口径仍为原型数值，不变更确认规则。美术采用本仓库原创可分发 SVG 与 CSS，直接内联；提示音本地合成，不加载音频。移动演出只读取已决定路径，不消耗 RNG；所有结算由 core 一次执行。

实际模拟发现标准经济经典模式可能极长：最初 6 局上限 12000 次操作，约千轮仍无淘汰。保留默认 1200/300 金；新增显式可选“紧张资金”实验预设 300/50 金（初始/俸禄），所有角色相同。它不改变经典胜利条件、不暗中限制轮数。后续报告同时列标准经典截断样本和紧张资金完成样本，不能将截断局排名计为胜利。
