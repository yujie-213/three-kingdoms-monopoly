# v1.5 经济系统（用户授权实施，2026-10-10）

目标：经典无限轮仍以其他势力破产结束。正常买地、适度建设时，地图第二圈仍有发展空间；中后期逐渐需要筹款与资产取舍。轮次是全部存活角色各行动一次，圈数是单个角色绕地图一次，二者不同。

## 标准新局

| 项目 | 参数 |
|---|---|
| 初始现金 | 3200 |
| 一圈基础补给 | 300，经过10/20/30/40格各75 |
| 开拓补助 | 前两圈每段额外50，一圈额外200 |
| 地价 | 150 / 250 / 400 |
| 升二级、三级成本 | 地价60% / 100%，四舍五入 |
| 一至三级基础租金 | 地价10% / 35% / 100% |
| 完整城组 | 租金+30%，每座城每圈40经营收益 |
| 三城组拥有两座 | 这两座租金+15%，无经营收益 |
| 商路 | 一座己方城池租金+25%，城组加成相加 |
| 普通负面事件上限 | 80 |
| 基础现金储备提示 | 600；下一骰可落敌地的最高租金+100若更高则提高建议 |

完整两城组每圈80、三城组120，经营收益仅在跨越起点且当时完整持有时结算，每组一次。起点不另发一笔整圈补给。每段补助按该段所属个人圈数计算，完成第二圈后立即停止开拓补助，不补发过去收入。

进阶紧张资金仍为500/80，无开拓补助；分段补给每段20，其他经营机制仍可用。该模式不承担标准模式的宽松起步体验目标。

每回合主动/落点建设共享一次，新买城池下回合才能升级。二级开局可建，三级须该玩家完成第一圈；零散城池仍可建设三级。修城令按实际支付记录折扣层。

## 骰子调度

首次掷骰后、移动前，若本圈未调度、现金够60且没有使用千里走单骑，进入落点选择。免费确认原点数，或付60调整±1，最终点数不超出骰子范围（标准1～6）。调度直接进入移动阶段，不能再次付费修改；不额外抽随机数。每圈最多一次，真正完成移动并跨起点才恢复，刷新、跳过或结束回合不恢复。急行军额外骰不能调度。

选择前显示原点数及±1的具体地点、购地价或应付租金。付费修改后的移动也保存快照，恢复后只结算一次。正常演出在调度选择前摇骰，确认后移动。

## 筹款与保护城组

欠款时，可整城出售或拆一层建筑，均需确认。拆三级到二级、二级到一级，返还该层实际建设投入的60%向下取整；相应折扣记录移除，剩余实际投入减少。土地、城组关系及该城剩余期限的商路保留。整城出售返还所有实际投入60%，归还系统，移除商路与折扣记录；拆散完整城组失去其经营收益，并重新计算其他城的租金加成。

默认筹款推荐优先零散资产，其次未完成连城，再完整城组的建筑，最后拆散完整城组。每档按租金/经营收入损失相对筹款额排序，AI同样使用这些公开选项，并在同档优先选择可一次偿清且损失较低的方式。玩家可选择任何合法资产。确认页显示筹款、偿债后余额或剩余欠款、租金和城组收入损失。

仍保留原破产判断：现金与整城全部可回收额仍不足偿债时破产；余款部分偿付，地产归系统，不转给对手。

## 商业繁荣

同时达到至少24座已持有城池、至少6座三级城时触发。记录当时已完成的公共轮次，初始倍率1；其后每12个完整轮次租金倍率+0.25。倍率按已完成轮次计算，所有玩家一致，无经典局轮数上限，也无临时租金倍率上限。触发后出售或拆建筑不会关闭或重置。

最终租金 = 四舍五入(地价 × 等级租金系数 × (1 + 城组加成 + 商路加成) × 繁荣倍率)。只提高租金；地价、建设成本、补给和城组经营收益不变。界面公开当前倍率、触发条件与距离下次增长的轮次。

这是应对后期平衡持有时持续现金注入的机制，不保证特定结束时间；须继续观察多人和两人残局。

## 持久化与兼容

JSON版本5保存调度次数、落点选择阶段和繁荣起始轮，收入从实际路径及已完成圈数推导，不新增可重复领取的按钮。自动保存沿用既有存储键以读取旧档，实际JSON为v5。

旧40格v3/v4迁移保留原价格、租金、俸禄、升级成本、RNG及模式；不注入分段补给、开拓补助、城组经营收入、调度或繁荣，原三级开放条件也保留。v3财富统计仍从迁移起累计。重新开始新局采用所选新版经济。旧24格v2仍拒绝。

## 初步核验

规则模拟报告：`reports/simulation-economy-v5.json`。标准经典30/30经破产结束，平均98.83轮，中位98，最长174；90个角色均走到第二圈结束，前两圈没有被迫出售/拆建筑，第二圈结束现金中位872。标准经典30场均触发繁荣。发生过筹款处置的68个角色，首次处置圈数中位5、最早3；实际卖过整城的67个角色，首次卖城圈数中位5、最早3（未处置角色不计入这两个中位数）。

这是公开规则AI策略的90场总样本（另含30场限轮、30场紧张资金），不是人类试玩或平衡证明。紧张资金平均191.33轮、最长450，30场均结束但均未触发繁荣；其节奏仍需单独评估。
