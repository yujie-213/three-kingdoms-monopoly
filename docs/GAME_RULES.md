## 首版操作

每次掷骰前可使用生财有道（+100）或千里走单骑（+2格）；空城计只在扣租前决定。一张锦囊一次消耗；同一次移动不能叠加两张加步锦囊。背包满时指定替换或放弃，不隐藏丢弃。

事件按经济65% / 行动20% / 策略15%抽取，再在该类内等概率有放回抽取。急行军每回合最多一次额外骰，重复仅提示，额外落点照常结算；军令延误跳过下次行动且仍计机会。普通罚款最多150金，税费/租金按各自规则。

驿站+60、集市税费80、渡口随机锦囊；隆中空城计、赤壁+50。地图名称/分布仍可迭代。资产整体出售前确认，偿清后自动完成原付款；不足则部分付款、余额免除、资产归无主、角色退出队列。

标准初始/俸禄1800/500，另可选紧张资金500/80；全体角色相同。经典标准经济可能很长，紧张资金用于实验。40轮是默认限轮，不是经典的隐藏上限。

导出JSON保存当前随机数、待移动/待决策/欠款等状态；合法导入确认替换，非法导入保留当前局。刷新不自动保存。暂停和速度仅控制演出，不改变账目。

## 已确认约束

- R01：魏蜀吴各一位主将（曹操、刘备、孙权）共同起点，1 真人 + 2 AI。
- R02：单向固定闭环道路，无岔路。
- R03：通过掷骰行动；1D6 仍是待确认建议。
- R04：停到无主土地可选择购买或放弃。
- R05：购地与一级建筑一次交易，买入立即一级。
- R06：停到自己 1/2 级土地可自愿升级，一次落点至多一级，最高三级；经过不能升级。
- R07：只有最终停到敌地才收租，经过不付费。
- R08：地段等级固定，与建筑等级分开；贵地购买、升级、收费均较高。
- R09：每完成一圈发一次俸禄，经过或恰停起点均有效，不能重复发放；开局站在起点不发奖。
- R10：现金不够支付可主动卖资产，仍不足才破产。
- R11：土地与建筑整体卖回系统，回收累计实际投入的 60%，随后归无主。
- R12：以经济事件为主，少量行动/策略事件；普通罚款有固定金额上限。
- R13：首版简单锦囊；免租必须在敌地扣款前询问使用。
- R14：经典破产与限轮排名两种终局，确认的默认为 40 轮。
- R15：全部存活角色各获得一次行动机会为一轮；跳过也计机会；AI 动画速度不能改变逻辑。
- R16：PC 优先，单个离线 HTML；后续静态站点与手机适配。

系统买卖/升级/税费与玩家间租金分开记录；未偿债务在破产时免除，无负现金或跨局欠款。一名存活者提前终局；40 轮必须在完整轮结束后结算。债务未处理不能结束回合；拒绝购买/升级不能偷偷执行。破产角色退出队列并归还未售资产。

AI 与真人使用相同合法接口，不知未来随机结果，没有隐藏优惠。存档需版本化并包含 RNG 状态，提供 JSON 导入/导出，不能仅依赖 file:// 的 localStorage。
