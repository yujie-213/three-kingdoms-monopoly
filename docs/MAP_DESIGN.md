# 40格区域地图与阵营设计

2026-10-09，按用户要求替换24格占位地图与刘关张身份。

环路分中原、荆襄、江东、巴蜀四段，每段10格，总计29土地、4事件、4设施、2主题、1行营。以汉末至三国时期的行政关系与城址为依据；不同地点采用的年代口径在详情中注明。路线是主题行旅，不是某一年疆域或真实道路里程图。地理区域与阵营占地分开，所有土地初始无主。

县城是普通县城，郡治代表郡治所在城址，名城表示都城或重要政治中心；这是游戏经济分类，不表示县、郡是同一种行政单位。行政层级另记录province、commandery、county，郡国及典农辖区保留真实称谓。郡治与该治所县不重复作为两块地。

魏/蜀/吴各一人，曹操/刘备/孙权为首版代表。魏使用曹操作阵营代表，并不表示曹操曾称曹魏皇帝。角色注册表与阵营定义分开，选阵营后显示其可选主将；核心按阵营选一位参战，未来增加角色无需增加玩家数。AI风格与主将分开。

地图路径索引、显示坐标和美术分开：本版以13列9行的矩形环路先展示40格，棋盘铺满中央窗口；未来可替换cellCoordinates为不规则路线，保留移动顺序与落点结算。人物为原创SVG，曹操和孙权另绘冠服及胡须；地块已有县城/郡治/名城建筑轮廓，精细区域美术留待下一版。

## 经济实验

标准1800初始 / 500圈俸禄，紧张资金500 / 80。地价150 / 250 / 400、租金与升级倍率、事件金额、60%回收保持不变。原24格平均约6.86次投骰一圈，新40格约11.43次（按1D6均值3.5，不计额外骰/跳过）。标准俸禄从300到500，使每路径格俸禄300/24=500/40=12.5，避免圈变长而收入速率下降。土地从13到29，落点土地密度54.2%到72.5%；初始金提高50%，让首圈较多购买机会有资金支撑。

72种子规则AI模拟：60限轮全部40轮完成、0破产；紧张资金经典6/6完成，平均247.83轮；标准经典0/6在2000操作内完成，平均203.33轮截断。不能把截断排名当胜利，也不能把小样本当平衡证明。下一次试玩应观察标准限轮决策压力，以及经典局时长。报告：reports/simulation-40.json；旧报告保留。
